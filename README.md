# PrisonHeist resource pack

Public download for Minecraft Java 1.21.4 (pack format 46).

The ZIP includes the existing Furadeira and the new Matadora I model. Both use vanilla textures. The SHA1 is recorded in `PrisonHeist-Furadeira.zip.sha1`.

Use the full commit hash in raw.githubusercontent.com download URLs so the ZIP and server resource-pack-sha1 remain pinned to the same revision. This repository contains no server credentials or player data.
